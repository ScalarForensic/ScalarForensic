# Security Policy

## Supported Versions

ScalarForensic is in the PoC phase and has no supported release/security-response SLA.

## Reporting a Vulnerability

Public issues and pull requests are the currently documented reporting channels.
Do not include case evidence, credentials, or sensitive deployment details in a
public report. No monitored private reporting channel is currently advertised.

See [the operations guide](docs/deployment.md) for deployment boundaries, process-level
examiner attribution, upload limits, state retention and backup responsibilities.
